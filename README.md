## Inception

Inception is a system administration project from the 42 Common Core focused on building a secure and modular web infrastructure using Docker. The project consists of setting up multiple containerized services that work together to host a functional website.

Using Docker and Docker Compose, the infrastructure includes services such as Nginx, WordPress, and MariaDB, each running in its own container and configured to communicate within a private network. The goal of the project is to understand containerization, service orchestration, networking, and environment configuration while following best practices for security and maintainability.
