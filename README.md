IRC is a network programming project from the 42 Common Core that involves building a fully functional Internet Relay Chat (IRC) server in C++. The server allows multiple clients to connect simultaneously, exchange messages, and interact within channels, following the core specifications of the IRC protocol. The project provides hands-on experience with socket programming, TCP connections, and the management of multiple clients in a concurrent environment.

The project focuses on building a reliable client-server architecture capable of handling real-time communication. It covers key concepts such as connection handling, event-driven programming, and efficient management of multiple networked clients. IRC demonstrates practical implementation of network protocols and low-level programming to create a multi-user chat application.
